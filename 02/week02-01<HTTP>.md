## ✏️ HTTP 한 줄 정리

- **HTTP**
    - 클라이언트가 웹 서버와 원할한 소통을 위해 사용하는 통신 규약
- **HTTP Message**
    - Request과 Response을 통해 데이터를 주고 받고 Header(Body 내용 요약)와 Body(리소스 본문)의 구조
- **HTTP Request Method**
    - 웹 서버에 구체적인 작업 지시를 내리는 명령어
    - 데이터 조회(GET), 리소스 생성(POST), 전체 업데이트(PUT), 부분 수정(PATCH), 리소스 삭제(DELETE)
- **HTTP Status Code**
    - 서버의 처리 결과를 숫자로 알려주며, 성공(200), 리다이렉션(300), 클라이언트 오류(400), 서버 오류(500)로 크게 분류하여 에러의 원인을 판단하는 기준이 됨
- **HTTP URL**
    - 웹 리소스의 고유 주소로 스킴(http/https), 도메인, 포트(80은 생략 가능), 리소스 경로, 그리고 ? 뒤에 오는 추가 매개변수(쿼리 스트링) 순으로 구성
